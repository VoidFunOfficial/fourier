# Clone 视频设计风格

这是一支以界面操作讲述 Work / Play 转换的 MG 宣传片。整体气质简洁、精密、轻盈，带有苹果产品传播中常见的留白与排版秩序，同时用柔焦彩色形体、流动渐变和银色金属细节增加感官吸引力。

高级感主要来自四件事：**有限的视觉元素、清晰的主次关系、连续的运动逻辑，以及细腻的材质变化。**

本文以提供的 `clone.mp4` 和本次 SDK 复刻成片为依据。主体约 19.05 秒，另有从 `ad-apple` 追加的 4 秒 “this video” 片尾。下列色值、字体名称来自复刻工程，可作为延续风格的起点，不代表原片制作文件中的精确参数。

## 1. 视觉主题：把操作过程变成视觉叙事

影片从创作工具图标出发，依次展示编辑轨道、导出进度、状态切换和游戏界面，最后落到 Work / Play。观众通过元素的移动、排列和变化理解内容，说明文字很少。

图标、色条和按钮既承担信息功能，也承担构图与转场功能。例如，开场散布的工具收拢为队列，接着成为编辑界面的轨道；加载条和金属开关共享横向胶囊轮廓，使相邻场景保持形状上的联系。

延续这一风格时，应先明确一个操作或状态变化，再设计对应的运动。每个镜头只突出一个主要动作，让观众知道正在看什么、发生了什么、接下来去哪里。

## 2. 配色：中性底色承托集中出现的彩色

浅灰与炭黑构成大面积背景，蓝、青绿、珊瑚粉和桃色集中出现在工具、轨道、光晕及品牌圆点上。鲜艳颜色具有较强的辨识度，柔化的边缘和渐变过渡又让它们保持温润。

| 角色 | 复刻工程色值 | 视觉作用 |
| --- | --- | --- |
| 浅灰底色 | `#DFDDE0` | 提供柔和、略带冷调的中性空间，承托彩色图形。 |
| 炭黑底色 | `#272526` | 用于加载、开关和品牌收尾，集中视线并形成节奏变化。 |
| 主蓝色 | `#506EE2` | 表达数字工具、操作和活力。 |
| 深蓝色 | `#3D5680` | 稳定画面，增加轨道和按钮的层次。 |
| 青绿色 | `#56B2A0` | 与蓝色形成柔和过渡，区分编辑内容。 |
| 珊瑚粉 | `#FB647C` | 提供醒目的暖色重心。 |
| 桃色 | `#FF8B83` | 软化冷暖交界，让色块更有光感。 |
| 追加片尾浅白 | `#F5F5F7` | 为文字署名提供安静、明亮的结束画面。 |

颜色在不同形态之间重复出现，帮助观众追踪元素身份。渐变以宽阔、模糊的色域互相渗透，内部缓慢流动；避免把所有颜色平均铺满整个画面。

## 3. 材质：柔焦色块与清晰信息并存

**彩色形体具有柔软的边缘。** 开场圆形工具像带有扩散光感的色团，局部边缘清晰，另一侧逐渐融入背景。遮挡、大小变化和不同程度的虚化，共同建立空间深度。

**色条内部持续变化。** 编辑轨道与进度条保持简洁的外轮廓，内部颜色缓慢漂移。即使主体暂时停住，画面仍然有细微生命感。

**金属质感只在关键位置强调。** 中段开关通过银灰明暗、窄边缘高光、柔和扫光和轻微内阴影产生厚度。反射受到控制，整体仍保持干净。

**细颗粒统一表面。** 很轻的纹理让大面积背景与渐变更有触感。颗粒应在观看时退居背景，不能抢过文字、轮廓和动作。

图标、数字和操作标签通常保持清晰。柔焦主要服务于色彩扩散、前后关系与运动方向，不能损害关键内容的可读性。

## 4. 造型与构图：少量几何形体，多种尺度关系

核心造型包括圆形、圆角矩形、胶囊、细线边框和简化图标。它们可以在不同场景中复用，形成统一的视觉语言。

构图随叙事改变：开场采用倾斜环绕与前后堆叠，编辑段转为有秩序的横向轨道，开关与品牌段回到中央，交互段则推近一个明确的按钮。画面经常保留大片空白，让单个对象获得足够关注。

界面细节有明显层级。游戏面板中，人物剪影和 Continue 按钮承担主要识别任务，标签、数值和能力条提供背景信息。细边框限定区域，面板本身保持轻薄。

尺度变化是重要的表现手段：小图标可以成为近景主体，普通进度条的圆角和百分比可以占据画面。放大围绕观众正在关注的对象展开，使镜头移动有明确目的。

## 5. 字体与文案：简短、精确、附着于内容

主体以现代无衬线字体为主，字重克制，字距略紧。文字通常作为界面标签、状态数字、按钮或品牌落款出现，位置与对应对象紧密关联。

复刻工程使用 Apple SF Pro 处理主体界面与英文，Montserrat Medium 用于原片的小号作者署名；追加片尾使用从 `ad-apple` 复用的 SF Pro 与 Heiti 字体。

字体层级通过字号、明度和空间位置建立。加载百分比在镜头推近时成为主体，Work / Play 以少量文字完成主题落点，原作者署名则保持很小的视觉占比。

追加片尾使用三行居中结构：灰色小标题 “this video”、最大的制作说明、较小的“独立完成”。三行依次轻微上移并显现，随后留出阅读时间。

## 6. 动效：流畅的路径、明确的落点、有因果的衔接

开场运动以弧线、椭圆式环绕和倾斜队列为主。元素沿连续路径改变位置，通过大小、遮挡和虚化表现前后关系。运动经过关键姿态时保持平滑，避免方向和速度突然折断。

编辑段的运动具有操作感：色条伸长、裁切、复制、错位排列，指针和播放头承担引导作用。动作完成后给出短暂停留，让结果能够被看清。

转场会继承前一镜头的颜色、方向或轮廓。例如，横向色条与胶囊开关在形状上呼应，指针点击 Continue 后进入品牌收尾。观众的注意力沿着这些联系向前移动。

主要物体进入或落位时使用缓入缓出，镜头快速推进后逐渐稳定。缓慢的材质流动与短促的操作动作形成速度差，整体有活力，同时保持可读性。

## 7. 节奏：展开、操作、聚焦、释放、停留

以下时间按本次 60 fps 复刻版近似标注。

| 时间 | 视觉节奏 | 设计目的 |
| --- | --- | --- |
| 0–3.17 秒 | 图标环绕、收拢、推近 | 建立色彩记忆与空间感。 |
| 3.17–8.25 秒 | 轨道展开，多次局部操作 | 通过动作传达创作过程。 |
| 8.25–11 秒 | 深色背景、加载、快速放大 | 将注意力收束到完成状态。 |
| 11–12.42 秒 | 金属开关出现并稳定 | 用材质变化承接工作与娱乐的转换。 |
| 12.42–14.63 秒 | 游戏界面展开，推近点击 | 展示转换后的场景，并给出明确落点。 |
| 14.63–19.05 秒 | 品牌标志、Work / Play、作者署名 | 减少运动与信息密度，让主题被记住。 |
| 19.05–23.05 秒 | 浅白背景、三行文字依次出现 | 完成本次追加的制作署名。 |

全片具有明显的疏密变化。快动作之后有稳定画面，复杂界面之后有单个符号，大面积彩色之后有中性背景。停留时间也是设计的一部分。

## 8. 声音与动作的关系

本次复刻主体保留参考片音轨，追加片尾复用了 `ad-apple` 对应段落的轻气流、短促点击与低频落点音效。

延续风格时，声音应围绕动作组织：气流对应移动和展开，短音对应点击或状态确认，低频强调重要落位。声音的起点、力度和余韵应与视觉动作一致，并在收尾处留出安静的阅读空间。

## 9. 延续风格时的重点

- 先建立中性背景与留白，再让少量彩色元素成为视觉重心。
- 保留清晰的图标和文字，把柔焦用在色场、边缘与空间层次上。
- 让同一对象在位置、形状和功能上继续发展，保持镜头之间的联系。
- 每次镜头推进都指向一个值得观看的细节，每次操作都给出可见结果。
- 用圆角、细边框、柔和高光和微弱纹理统一材质，控制装饰密度。
- 将文字放在需要解释的对象附近，给关键状态和最终落款留出阅读时间。

可用于后续设计说明的概括：**以浅灰和炭黑留白空间承托柔焦蓝、青绿、珊瑚色形体，用精密的界面排版、连续的几何运动和克制的镜头推进，呈现轻盈、有触感的数字产品体验。**
